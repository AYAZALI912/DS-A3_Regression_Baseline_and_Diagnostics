This project builds an interpretable regression baseline for daily solar-wind speed using the supplied OMNI dataset. After converting common fill values to missing, constructing dates, sorting chronologically, and removing incomplete rows, 19,019 usable observations remained. Data were split into 70% training, 15% validation, and 15% test data in time order to reduce temporal leakage. The target was solar-wind speed; predictors were proton density, IMF magnitude, GSM Bz, and flow pressure.

A training-median dummy model was used as the naive baseline. Linear regression, ridge regression (alpha=1), and lasso regression (alpha=0.01) were evaluated with median imputation and standardization. Model selection used validation RMSE only. The selected model was Linear regression; on the held-out test set it achieved MAE 65.45 km/s, RMSE 78.81 km/s, and R-squared 0.244. The median baseline achieved test RMSE 90.67 km/s. Residual plots and prediction-range error slices are included to check systematic errors and changing variance.

These results support only a baseline predictive comparison, not a causal claim. Temporal dependence, missingness, positional column mapping, and future distribution shift limit interpretation. The repository should retain the dataset version, code, environment requirements, raw metrics, report, and AI-use disclosure. The column mapping should be independently checked against official OMNI2 documentation before scientific reuse.
